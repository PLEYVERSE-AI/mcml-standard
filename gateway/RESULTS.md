## Limits of these results

- **Synthetic environment.** No real clinical systems, models or patients.
- **Isolation is simulated by credentials.** The tool accepts calls only with a credential the gateway holds. In production, network or host controls must also stop the agent reaching tools directly. Scenario 4b shows what happens when that isolation is misconfigured: the call succeeds, and reconciliation detects it afterward.
- **Attestation is simulated.** The serving host signs the hash of its weights. Real deployments need hardware- or platform-backed attestation.
- **In-flight calls.** A kill switch blocks every call after activation; it does not abort a tool call already executing.
- **Declared limits only.** An action the card permits can still cause harm, and a well-formed call the agent was manipulated into making passes payload validation.
